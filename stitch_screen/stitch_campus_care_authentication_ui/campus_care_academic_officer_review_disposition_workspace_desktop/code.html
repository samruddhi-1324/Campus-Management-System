Problem 4(B): Directed to Undirected Reduction [25 Pts] Score: 07 / 25

"Provide a polynomial-time reduction algorithm that maps an arbitrary directed graph G = (V, E) into an undirected graph G' such that G has a directed Hamiltonian path if and only if G' has an undirected Hamiltonian path."

Construction: Let G' = (V', E') where each vertex v ∈ V is replaced by a triplet (vin, vmid, vout). Internal edges: {(vin, vmid), (vmid, vout)}. For each directed edge (u, v) ∈ E, instantiate an undirected edge (uout, vin).
Soundness Argument: By CLRS Lemma 3.4 (Cycle Preservation under 3-tuple vertex transformation), any traversal entering vin must traverse vmid prior to exiting through vout without retracing.
